# Шаблон игры Three

Чистая основа браузерной 3D-игры на Vite + Three.js с интеграцией Яндекс Игр. Выделена из проекта `rating`, но не содержит его предметов, изображений, персонажей, голосов, статистики и игровой логики.

## Что уже есть

- адаптивный WebGL canvas без системных полос прокрутки;
- стартовый экран и вызов `LoadingAPI.ready()` только после загрузки и отрисовки;
- `GameplayAPI.start()` / `stop()`;
- пауза игры и звука при рекламе, потере фокуса и событиях платформы;
- полноэкранная и rewarded-реклама;
- sticky-баннер только на достаточно высоких мобильных экранах;
- язык из `ysdk.environment.i18n.lang` и ручное переключение RU/EN;
- первый пользовательский жест для разблокировки звука;
- локальное и облачное сохранение через `player.getData()` / `setData()`;
- методы авторизации, лидербордов и покупок;
- отключение контекстного меню только внутри игровой области;
- безопасный локальный режим, если `/sdk.js` недоступен.

## Перед новой игрой

1. Переименуйте проект и замените тексты в `src/core/i18n.js`.
2. Укажите ключ сохранения, имя лидерборда и ID покупок в `src/config.js`.
3. Замените демонстрационный объект и игровую логику в `src/game/game.js`.
4. Добавьте ресурсы в `public/` и дождитесь их загрузки в `Game.load()`.
5. Настройте звуки через `AudioManager.register()`.
6. Оставляйте `LoadingAPI.ready()` в конце инициализации, после появления стартового экрана.
7. Вызывайте полноэкранную рекламу только в логических паузах геймплея.
8. Выдавайте rewarded-награду только внутри `onRewarded`.
9. Для консумируемых покупок сначала восстанавливайте `getPendingPurchases()`, выдавайте товар и только затем вызывайте `consumePurchase()`.
10. Для облачных сохранений отметьте соответствующий пункт в Консоли Яндекс Игр.

## Команды

```bash
npm ci
npm run dev
npm run build
```

Локально SDK может быть недоступен — приложение продолжит работу без платформенных функций. Для полноценного тестирования SDK используйте черновик в Консоли Яндекс Игр или официальный dev-proxy.
